수집 방식
★ 내 프록시 (Google Apps Script) 가장 안정적 · 무료

공용 변환 서비스는 자주 막히거나(401·503) 느려집니다(시간 초과). 내 구글 계정에 5분이면 만드는 전용 프록시를 연결하면 이 문제가 사라집니다.

  1. script.google.com 에서 새 프로젝트를 만들고, 기존 코드를 지운 뒤 위 버튼으로 복사한 코드를 붙여넣고 저장
  2. 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 유형 웹 앱 선택
  3. 다음 사용자 인증 정보로 실행: 나 · 액세스 권한: 모든 사용자 → 배포 → 권한 승인(“고급 → 안전하지 않음으로 이동” 눌러 허용)
  4. 표시된 웹 앱 URL(…/exec 로 끝남)을 아래에 붙여넣기 → 연결 진단으로 확인

※ 회사 Google Workspace 계정은 ‘모든 사용자’ 배포가 막혀 있을 수 있으니 개인 Gmail 계정을 권장합니다. 이 프록시는 Google News RSS 수집 · Google 기사 링크 해독 · 언론사 기사 페이지 조회만 처리합니다.
※ v5에서 이미 배포했다면: 새 코드로 교체 후 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포를 해야 원문 요약 기능(v2)이 켜집니다. URL은 그대로입니다.

공용 RSS 수집 경로 (켜진 경로를 동시에 호출해 가장 먼저 성공한 응답을 사용)

⚠ GNews 무료 플랜은 브라우저 호출(CORS)을 localhost에서만 허용합니다. 파일로 열거나 GitHub Pages에 올리면 막힐 수 있으며, 이 경우 오류 원인이 표시됩니다. 무료 플랜 기사는 12시간 지연됩니다.

무료 플랜은 하루 200 크레딧, 최근 48시간 기사만 제공되며 기사가 지연될 수 있습니다.

연결 진단

이 환경()에서 각 수집 경로가 실제로 동작하는지 하나씩 시험합니다.

EmailJS는 서버 없이 브라우저에서 바로 메일을 보내주는 서비스입니다. 무료 계정으로 시작할 수 있으며 최초 1회 아래 3단계 설정만 하면 됩니다.
  1. 1. 메일 서비스 연결

    emailjs.com 가입 → Email Services → Add New Service → Gmail 등 연결 → Service ID 복사

  2. 2. 템플릿 만들기

    Email Templates → Create New. 아래 값을 그대로 넣고 저장 → Template ID 복사

  3. 3. Public Key 복사

    Account → General → Public Key를 복사해 아래에 붙여넣고 테스트 발송을 누릅니다.

To Email   : {{to_email}}
Subject    : {{subject}}
Content    : (편집기 우측 'Code' 또는 '</>' 모드에서) {{{report_html}}}
             ※ 중괄호 3개여야 표가 HTML로 표시됩니다.

현재 대시보드에 수집된 기사로 리포트를 만들어 바로 발송합니다. 무료 플랜은 월 발송 횟수 제한이 있습니다.

보안 팁: Public Key는 공개용 키라 HTML에 노출되어도 되지만, 다른 사람이 악용하지 않도록 EmailJS Account → Security에서 허용 도메인(예: GitHub Pages 주소)을 지정해 두는 것을 권장합니다.

1단계 원문 본문을 r.jina.ai → 내 프록시 → allorigins/get → codetabs 순서로 끝까지 시도해 가져온 뒤, 키워드 가중치로 실제 기사 문장 2~3개를 골라 요약합니다. AI 키가 있으면 AI가 3줄 브리핑으로 다듬습니다.
2단계 그래도 원문이 막히면, 형식적인 안내 문구 없이 기사 리드(메타 설명) + 메인 헤드라인 + 관련 보도의 새로운 내용을 조합한 2~3줄 사실 요약을 만듭니다.
팁: ‘내 프록시(Apps Script)’를 연결하면 Google News 신형 링크 해독과 언론사 페이지 조회까지 내 계정에서 처리해 원문 요약 성공률이 크게 올라갑니다.
요약 방식

키는 이 브라우저에만 저장되며, AI 요약 시 기사 본문 일부(최대 약 3,500자)가 선택한 AI 서비스로 전송되고 사용량에 따라 요금이 부과될 수 있습니다. 모델명은 서비스에서 사용 가능한 이름으로 바꿀 수 있습니다. AI 호출이 실패하면 무료 자동 추출 요약으로 자동 대체됩니다.
